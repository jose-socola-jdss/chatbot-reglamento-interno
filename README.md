# Chatbot De Reglamento Interno

Aplicacion interna para consultar un reglamento laboral ficticio cargado localmente. El chat responde solo con esa base y muestra articulos citados con extractos.

## Ejecutar

```bash
npm install
npm run dev
```

## Incluye

- Base local estructurada por secciones del reglamento.
- Chat con prompts rapidos, historial local y respuestas con referencias.
- Navegacion lateral tipo FAQ para lanzar consultas contextuales.
- Mensajes de limite cuando la consulta no existe en la base cargada.
## Modos de uso

- Desarrollo: `npm install && npm run dev`
- Archivo estatico: ejecuta `npm run build` y abre `index.html` en la raiz del proyecto.
